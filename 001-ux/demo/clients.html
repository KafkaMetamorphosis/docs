How clients work

A client is only an identity and a set of labels. It carries no Read or Write role of its own — every permission comes from the access policy of the channel it connects to, evaluated against the client's FRN and labels (zero trust: no matching statement means no access).

Consumer groups are not registered here. When a client subscribes to a channel it uses a group named <client>.<topic> by default, or a custom group it supplies. Telemetry Agents report the groups they observe, along with the client and owner behind each one, which is what populates the column above.
