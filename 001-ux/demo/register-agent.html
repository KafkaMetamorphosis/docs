Register Agent

Record an agent that will connect to the Franz fleet API and act on fleet data.

Agent details

Registration records the agent in the control plane. Franz does not connect to the agent, test it, or provision anything from this screen.

Identity and type

The agent connects to the fleet API with this identity and acts within the slice of the fleet it is responsible for.

Type is used to filter and organise agents. It does not change how the agent connects. See what each type is responsible for.

Fleet API connection

The agent pulls its work and pushes results through the fleet API. Franz never calls the agent.

gRPC is the only supported protocol. Agent credentials, connection testing, and liveness are outside this flow.

Context selector

The slice of the fleet this agent is responsible for. Franz only hands the agent work that matches this selector.

Leave empty for an agent that operates on the whole fleet.

Telemetry protocol

A Telemetry Agent must publish indicator data over the fleet API following the telemetry protocol: each sample carries an indicator name, a value with its unit, and the resource it describes. Franz records the samples and exposes them as indicators on the Governance screen.

What happens next?

Franz records this agent in the control plane. The agent connects to the fleet API, pulls the work that matches its context selector, and reports results. Franz never connects to the agent and never acts on infrastructure itself.
