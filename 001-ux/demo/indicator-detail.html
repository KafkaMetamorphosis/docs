replica-size

Indicator Healthy

Overview

Total on-disk size of all replicas of a topic, summed across the clusters it is placed on.

Unitbytes (shown as Gi / Ti)
Applies toKafka Topic
Source agentskafka-telemetry-br, kafka-telemetry-us
Sample interval~60 seconds per topic
Staleness threshold15 minutes — beyond this the indicator is marked stale and policies reading it do not act
ProtocolTelemetry protocol over the fleet API
