Agent types

Type is an organisational filter. Every agent connects to the fleet API the same way.

TypeResponsibilityExamples
Cluster ProviderDeploys and maintains the substrate that hosts a fleet resource — Kafka clusters, RabbitMQ, and similar.br-prod-msk, br-prod-strimzi, local-docker
Resource ProviderRealises the individual resources on a substrate — Kafka topics, RabbitMQ queues, SQS queues. Gregor Samsa is a Resource Provider for Kafka topics.gregor-samsa-br-prod, sqs-bridge-us
Telemetry AgentPublishes indicator data to Franz following the telemetry protocol. Governance policies read these indicators.kafka-telemetry-br, broker-metrics-collector
CustomAny other program that reads from or acts on fleet data through the API.fleet-audit-exporter
