Create Async Channel

Create a customer-facing asynchronous communication boundary managed by Franz.

Channel details

A `kafka-topic` channel generates one or more linked Kafka Topic entities.

Channel details

The Async Channel is the primary resource managed by your service team.

Franz uses channel information to generate the Kafka topic name and channel ORN.

Kafka topic is the only supported type in the current experience.

This controls how many Kafka topics Franz creates for the Async Channel. It is distinct from Kafka topic partitions.

Placement context

Select the labels for the one context where this channel should live.

Franz persists this as the authoritative selector: org.com/env, org.com/country, and org.com/shard. Readable summary: br-prod-s8.

Access policy

Which clients may use this channel, in the style of an S3 bucket policy. Zero trust — a client with no matching statement has no access. Editable later on the channel.

Add at least one statement, or leave empty for a closed channel.

Generated Kafka Topic

Kafka-specific settings belong to the linked topics that Franz generates after the channel is created.

Kafka topic name: generated by Franz after creation Configuration: partitions, retention, replication factor, and additional Kafka topic settings
