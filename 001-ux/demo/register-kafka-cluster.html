Register Kafka Cluster

Record a Kafka Cluster in the control plane and describe its context using fleet labels.

Cluster details

Registration records declared intent only. Franz does not validate or connect to the cluster from this screen.

Identity and endpoint

Use an immutable, recognizable name for this fleet resource.

No connectivity validation occurs during registration.

Cluster Provider

The Cluster Provider agent that deploys and maintains this cluster's substrate. Franz stores the link; the agent does the work.

Leave empty for a cluster whose infrastructure is managed outside Franz. You can link an agent later. Register an Agent.

Context labels

Add every label that describes this cluster's context. Franz does not supply default labels or label namespaces.

Add at least one label. Labels are the authoritative context representation.

What happens next?

Franz records this Kafka Cluster in the control plane. Agents are responsible for interactions with real-world Kafka resources. Connection testing, TLS, authentication, broker discovery, and agent installation are outside this flow.
