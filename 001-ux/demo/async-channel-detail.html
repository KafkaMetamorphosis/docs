Access policy

One policy document per channel, in the style of an S3 bucket policy. Each statement Allows or Denies; an explicit Deny always wins, then an explicit Allow, otherwise no access (zero trust).

A statement matches by FRN, by labels (= and IN (…)), or both. * is a wildcard in the FRN and in label values. :permissions is one or more of :read :write.

Discovery and SDK usage

The Franz SDK is the only supported way for a service to discover and use this Async Channel.

Initialise the SDK with the channel FRN and the client FRN, and provide the client's Franz token through an environment variable. Franz evaluates this channel's access policy against the client before allowing publish or subscribe; the SDK then resolves the channel's current Kafka location.

export FRANZ_TOKEN=<your-franz-access-token>
// Illustrative Franz SDK API var channel = FranzAsyncClient.builder() .channelFrn("frn:acme-platform:async-channel:billing-events") .clientFrn("frn:acme-platform:client:billing-ingestor") .token(System.getenv("FRANZ_TOKEN")) .build(); channel.publish(event);
// Illustrative Franz SDK API channel, err := franz.New(franz.Config{ ChannelFRN: "frn:acme-platform:async-channel:billing-events", ClientFRN: "frn:acme-platform:client:billing-ingestor", Token: os.Getenv("FRANZ_TOKEN"), }) if err != nil { return err } return channel.Publish(ctx, event)
