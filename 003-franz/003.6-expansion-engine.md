# Topic Definition Expansion Engine — superseded

Status: **superseded**

Expansion is no longer a standalone engine. When an **Async Channel** is created or
updated, Franz performs placement as a step of that operation
(see `003.4-topic-cluster-selection.md`): match the channel's context selector to
eligible clusters, honour `franz.affinity/shard-size` and taints, and create the
**Kafka Topics** and their first **Topic Revisions** in the same transaction.

The mechanics this document described — a `franz.logic.expansion` /
`franz.ops.expansion` split, an asynchronous re-expansion queue, and a dedicated
stale-revision guard — are dropped. The reconciliation guarantees now come from the
Topic Revision model in `003.3-kafka-topic.md`.

The original content is preserved in git history.
